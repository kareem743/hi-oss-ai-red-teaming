# BRITE login branding

The Medical Tool uses a split-screen app-owned login with WorkOS AuthKit. Red Teaming retains its Cloudflare Access OTP enforcement and uses the original Medical Tool layout, logo, font and colors in the app-owned access-status screen. The Cloudflare-hosted OTP screen remains unchanged: the account rejected custom login template validation with HTTP 403, error 12133. Full app-specific custom Access HTML/Liquid templates require a supported paid Zero Trust plan. Do not replace Cloudflare policy with an unprotected route or reuse another application's WorkOS credentials. A future WorkOS migration requires separate redirect configuration, secret bindings, verified-email session handling, revocation tests, and end-to-end OTP testing before replacing Access. No subscription or auth policy changes were made.
