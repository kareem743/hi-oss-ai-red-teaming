# UI and security refinement

Volunteer approval is separate from assignment. Private scenario creation accepts only active approved volunteers. The picker supports search, checkboxes, and removable selection chips. Model catalog discovery is admin-only and uses fixed OpenAI and Anthropic API URLs with Worker secrets, returning model IDs and display names, not credentials. OpenAI catalog entries are filtered to likely chat candidates; listing does not establish chat compatibility. Anthropic lists up to 100 models. Manual model IDs remain supported. No arbitrary endpoint/key probing. Daily model-call limit: 50 per volunteer, with an 80,000-character context cap. Mutations require matching Origin in the live environment. Local mock requests omit Origin by design; explicit foreign origins are rejected. The existing verified JWT and D1 authorization remain in place. WorkOS AuthKit is a future optional identity migration, not needed for authorization; do not copy the Medical Tool's credentials or alter its login configuration.
